# Week 1 - XUV700 Data Preparation and EDA

## Project Title

Data Cleaning, Preprocessing and Exploratory Data Analysis of Mahindra XUV700 Sales Data

## Objective

The objective of this project is to simulate the data preparation process required for a data science project.

The project covers:

- Data acquisition
- Data inspection
- Data cleaning
- Missing value handling
- Duplicate removal
- Data type correction
- Data preprocessing
- Exploratory data analysis
- Statistical analysis
- Data visualization
- Insight generation

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset

The dataset contains selected publicly available Mahindra XUV700 sales observations.

The dataset contains:

- Month
- Fuel Type
- Sales Units
- Export Units

## Data Cleaning

The following data-cleaning operations were performed:

1. Missing value identification
2. Duplicate detection
3. Duplicate removal
4. Missing value handling
5. Data type conversion
6. Invalid record removal

## Exploratory Data Analysis

The project includes:

1. Missing value visualization
2. Sales trend analysis
3. Fuel type sales comparison
4. Sales distribution
5. Correlation analysis
6. Outlier analysis

## Visualizations

The following visualizations are generated:

- Missing Values
- Sales Trend
- Fuel Type Sales
- Sales Distribution
- Correlation Heatmap
- Sales Box Plot

## How to Run

Install the required libraries:

pip install -r requirements.txt

Navigate to the code folder:

cd code

Run the Python program:

python xuv700_analysis.py

## Output

The program generates:

- Cleaned CSV dataset
- Statistical analysis
- Six visualizations
- EDA results

## Conclusion

This project demonstrates the fundamental data preparation and exploratory data analysis workflow used in data science projects.
